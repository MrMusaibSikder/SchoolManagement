# Project Context

## Project Name

School Management System (School ERP)

---

# Project Overview

This is a modern, enterprise-grade School ERP designed for educational institutions in Bangladesh.

The system is intended for real-world commercial use, not as a demo or learning project.

The frontend must be professional, responsive, scalable, and easy to maintain.

The backend is already completed using ASP.NET Core Web API.

Your responsibility is ONLY the React frontend.

---
