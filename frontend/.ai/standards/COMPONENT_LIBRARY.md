# Component Library

## Purpose

This document defines the official reusable component library for the School Management System.

Every feature must reuse existing components before creating new ones.

Never duplicate UI.

Never duplicate business components.

Always check this document before creating a new component.

# Permission Components

The School Management System uses a Role-Based Access Control (RBAC) architecture.

Every page, module, component, action, button, menu, widget, report, and API interaction must respect the authenticated user's permissions.

Never rely only on frontend permission checks.

Frontend permissions are for user experience.

Backend permissions are the final authority.
