# Review Checklist

## Purpose

Before marking any task or module as complete, review it using this checklist.

A module is only considered complete when every applicable item passes.

---

# Code Quality

✓ Clean and readable code

✓ TypeScript only

✓ No `any` unless absolutely necessary

✓ No duplicate code

✓ Reusable components used

✓ Meaningful naming

✓ No commented code

✓ No console.log

---

✓ Tables are consistent

---

# Completion Rule

Only mark a module as **Completed** if every applicable checklist item has passed.

If any critical issue remains, keep the module status as **In Progress** until it is resolved.
