# UI Reference

## Design Goal

Create a modern, premium, commercial School ERP interface.

The application should feel clean, fast, and professional.

---

# Layout

Desktop

Sidebar + Header + Content

Mobile

Drawer + Header + Content

---

# Sidebar

- Collapsible
- Searchable
- Permission Based
- Active Menu Highlight
- Icons

---

# Header

Contains

- School Logo
- Search
- Notifications
- Profile
- Theme (Future)

---

# Dashboard

Include

- Statistics Cards
- Charts
- Calendar
- Recent Activities
- Recent Notices
- Quick Actions

---

# Forms

Use

- Card Layout
- Two-column layout on Desktop
- One-column on Mobile

Always include

- Page Title
- Breadcrumb
- Save
- Reset
- Cancel

---

# Tables

Always support

- Search
- Filter
- Pagination
- Sorting
- Status Badge
- Action Menu

---

# Colors

Primary

Blue

Success

Green

Warning

Orange

Danger

Red

Background

Light Gray

Text

Dark Gray

Avoid bright colors.

---

# Border Radius

Cards

Medium

Buttons

Medium

Inputs

Medium

Dialogs

Large

---

# Shadow

Use soft shadows.

Avoid heavy shadows.

---

# Spacing

Use consistent spacing.

Avoid crowded layouts.

---

# Typography

Headings

Bold

Body

Readable

Labels

Medium Weight

---

# Icons

Use only

Lucide React

---

# Responsive

Support

Desktop

Laptop

Tablet

Mobile

---

# Empty State

Every page should have

- Illustration
- Title
- Description
- Action Button

---

# Loading

Prefer Skeleton over Spinner.

---

# Notifications

Use Toasts.

Avoid browser alerts.

---

# Rule

Every new page must follow this design system.

Never create inconsistent layouts.
